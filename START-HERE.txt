START HERE

This ZIP contains the complete editable website project, all website images,
self-hosted fonts and licence notices, calendar downloads, and the latest
compiled Worker build. It includes the smaller matching jasmine dividers,
refined date flower ring, top-right day/night control, door-entry animation,
sharing options, and the pavilion image corrected to fill the section width.

1. EXTRACT THE ZIP

Extract the entire Likitha-Jeevan-EInvite folder to your computer. Keep its
folders together, including the .openai folder. Work from this folder in a
terminal. Some file managers hide folders beginning with a dot.

2. INSTALL AND OPEN LOCALLY

Use Node.js 22.13.0 or newer, with npm. An internet connection is needed for
the first dependency installation. The dependency versions are locked in
package-lock.json; node_modules is installed locally rather than bundled.

Run:

    npm run install:ci
    npm run dev

Open the local URL printed in the terminal. The development port defaults
to 5173. Keep that terminal running while viewing the invitation.

This is a Vinext/React web application. It must run through its web server;
it is not a single index.html file that can be opened by double-clicking.

3. VIEW OR REBUILD THE PRODUCTION VERSION

After installing dependencies, preview the included build with:

    npm start

Open the URL printed by Wrangler in the terminal.

After editing the source, rebuild and preview with:

    npm run build
    npm start

The source and included build correspond to the same published revision.
Framework-generated Node prerender metadata is excluded from the export;
the configured Wrangler Worker does not require it. A rebuild regenerates it.

5. PUBLISHING / DEVELOPER HANDOFF

The built application targets Cloudflare Workers. Keep dist/server and
dist/client in their current relative locations. dist/server/wrangler.json
is the deployment configuration, with index.js as the Worker entrypoint.
Deploy both the Worker and its client assets through your chosen hosting
workflow. Uploading only dist/client to ordinary static hosting will not
reproduce this application.

For a new domain, first update invitationUrl in app/ShareInvitation.tsx and
metadataBase in app/layout.tsx, then run npm run build. Asset paths assume
the invitation is hosted at the domain root.

The .openai/hosting.json file identifies the existing ChatGPT Site and is
imported by vite.config.ts. Preserve it when working with this existing Site.
For a separate new Site, let the hosting workflow create its new identity.
The original live link's audience/login settings are managed by its host;
configure access separately if publishing the downloaded project elsewhere.
