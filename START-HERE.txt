LIKITHA & JEEVAN — E-INVITATION PROJECT

START HERE

This repository contains the editable invitation, temple illustrations,
self-hosted fonts, music and calendar downloads. The README describes the
current features and hosting setup. EXPORT-INFO.json records the original
ZIP export; its revision and file counts are historical.

1. INSTALL AND OPEN LOCALLY

Use a Node.js version compatible with package.json and install the locked
dependencies from the repository root:

    npm run install:ci
    npm run dev

Open the local URL printed in the terminal. This React application needs
its web server; it is not a standalone HTML file to open by double-clicking.

2. DEPLOY ON VERCEL

The connected GitHub repository is:
https://github.com/pratham19980315/likithainvite

vercel.json selects Next.js and runs npx next build. In the Vercel project,
use the repository root, the Next.js framework preset and the default
Output Directory. Leave the Output Directory override disabled. A push to
the connected main branch triggers Vercel's deployment workflow.

For a local production check matching Vercel:

    npx next build
    npx next start

The ordinary npm run build command retains the original Vinext/Sites
build workflow. It is not the Vercel build command.

5. MEDIA AND SHARING

Music starts only when a visitor taps the music button. The original
synthesized flute-style track is public/audio/wedding-flute.mp3, with a
75% starting volume and an adjustable volume slider. It uses no third-party
recordings or samples. Instructions and source are in scripts/audio/.

The social-preview image is public/images/og-wedding-landscape.jpg,
1200 × 630 pixels. Open Graph and Twitter metadata use this landscape image.
The generated illustrations are decorative and are not venue site plans.
Font licence notices remain alongside the local font files.

Share invitation uses the address where the visitor opened the website.
For a custom canonical/social domain, set NEXT_PUBLIC_SITE_URL to the full
HTTPS URL in Vercel and redeploy. Otherwise the metadata uses Vercel's
production-domain environment variable, with the original Sites domain
as a fallback outside Vercel.

This invitation does not require a database. Keep credentials and local
environment files out of the repository. Preserve the existing Sites
configuration when using the original Sites workflow.
